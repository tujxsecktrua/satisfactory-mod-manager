## Overview

Satisfactory Mod Manager (SMM) is the official modding hub for Satisfactory, tightly integrated with the ficsit.app community mod repository for one-click installation, automatic dependency resolution, and multi-profile management. It supports both Steam and Epic Games Store installations and keeps mods in sync with game updates, ensuring your factory build always has the right modlist.

Whether you're a newcomer just getting started or a seasoned pro looking for advanced tools, **Satisfactory Mod Manager** delivers the features you need in a clean, intuitive package.

## Key Features

| Feature | Description |
|---------|-------------|
| **ficsit.app Integration** | Browse the full community mod catalog and install with a single click |
| **Dependency Resolution** | Automatically downloads and installs all required mod dependencies |
| **Profile System** | Save, switch, and share different mod configuration profiles |
| **Steam + Epic Support** | Detects and manages both Steam and Epic Games Store installations |
